BLOK:
1. Dodaš u Enume EBlockType i EItemType, rebuild.
2. Dodaš u Content/Data/Blocks.json
3. Importaš T_ teksture u Editor u Content/Blocks/Textures
4. Tools -> pa OBA alata (jedan za blok, drugi za item)

EXTRUDANI ITEM (Mač, Stick, ...)
1. Dodaš u Enum EItemType, rebuild.
2. Dodaš T_Item_Stick.png u Content/Items/Textures/
3. Tools -> Generate Items Sprites
4. U Content/Data/Items.json promijeni Stick zapis sa "display": { "type": "none" } na:
"display": { "type": "sprite", "texture": "Stick" }
