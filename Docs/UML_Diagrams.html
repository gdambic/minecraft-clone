1.Legenda notacije

+ public  ·  # protected  ·  − private
podcrtano = static
kurziv = virtual ili apstraktna klasa
«AActor» = bazna klasa iz Unreal Enginea
◁— nasljeđivanje (generalizacija)
◆— kompozicija (vlasništvo, dijeli životni vijek)
◇— agregacija (referenca, neovisan životni vijek)
- - ▷ ovisnost (koristi / spawna)
Isprekidani sivi okvir u stablu = klasa Unreal Enginea, nije dio projekta

2.Hijerarhija nasljeđivanja

Sve klase projekta izvode se iz Unreal baznih klasa. Vlastita apstraktna hijerarhija projekta je ACreatureBase → AEnemyBase/AMobBase → konkretna bića.
