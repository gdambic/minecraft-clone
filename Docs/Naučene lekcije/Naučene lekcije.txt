Importamo gltf datoteku s modelom, teksturom i animacijama.

Obavezno stavio da forsirano kreira sekletal mesh (inače dobijemo hrpu nepovezanih static mesheva).

Kad smo je primijenili na ovcu, tekstura je bila mutna. Napravili smo novi materijal s tom teksturom (TextureSample node, pa Roughness na 1), i na teksturi PNG podesili:

┌──────────────────────┬────────────────────────────┐
│       Postavka       │         Vrijednost         │
├──────────────────────┼────────────────────────────┤
│ Texture Group        │ 2D Pixels (unfiltered)     │
├──────────────────────┼────────────────────────────┤
│ Filter               │ Nearest (Advanced sekcija) │
├──────────────────────┼────────────────────────────┤
│ Mip Gen Settings     │ NoMipmaps                  │
├──────────────────────┼────────────────────────────┤
│ Compression Settings │ UserInterface2D (RGBA)     │
├──────────────────────┼────────────────────────────┤
│ sRGB                 │ ✅ uključeno               │
├──────────────────────┼────────────────────────────┤
│ Never Stream         │ ✅                         │
└──────────────────────┴────────────────────────────┘
